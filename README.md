## Scope of this submission

This phase covers problem framing, literature review, dataset selection, and system
design only. It proposes an approach and a plan — no model training results,
evaluation metrics, or implementation are included, since those are the subject of
Phase 2 (CA2), submitted separately.

## Report sections

1. Title and Objective
2. Problem Statement
3. Literature Context (5 subsections, including preprocessing and class-imbalance
   approaches in prior work)
4. Dataset Details (3 datasets, one per planned module)
5. Methodology and System Design (architecture, preprocessing plan, per-module design,
   evaluation plan, integration plan)
6. Risk Assessment and Mitigation Strategy
7. Ethical Considerations and Data Privacy
8. Team Responsibilities and Project Timeline (6-week schedule)
9. Glossary of Key Terms
10. References
